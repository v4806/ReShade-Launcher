ReShade & Mod 런처 - 소프트웨어 소개

중요한 보안 성명
이 소프트웨어는 프로세스 주입 기술을 사용하여 ReShade 그래픽 향상 및 Mod 로드 기능을 구현합니다. 이러한 기술 메커니즘은 보안 소프트웨어에 의해 잠재적 위험으로 오진될 수 있지만, 실제로는 게임 그래픽 최적화 및 모드 관리에만 사용되며 악의적인 행위를 포함하지 않습니다. 주입 기술에 대한 보안 우려가 있는 경우 주의해서 사용하십시오.

기본 사용 방법
• 설치
• 프로그램을 처음 실행할 때 지시에 따라 게임 메인 프로그램 또는 XXMI 런처 선택
• 이후 시작 시 설정을 반복할 필요 없음
• 데스크탑 바로 가기를 통해 원클릭 게임 시작
• 게임에서 Home 키를 눌러 ReShade 효과 패널 토글
• Mod 파일 저장 경로: 설치 디렉토리\Mods_Loader\mods

핵심 기능
• XXMI를 사용하여 게임을 시작할지 선택 가능
• 게임 기본 파일과의 충돌을 피하기 위한 외부 ReShade 로드
• 그래픽 향상 효과와 게임 Mod를 동시에 로드하는 자동화된 시작 프로세스
• 시스템 언어 환경에 적응하는 다국어 인터페이스
• 구성 파일 자동 백업 메커니즘
• 통합 Mod 로더 (선택 기능, 필요에 따라 사용)
• 사전 설정 최적화 매개변수, 개봉 즉시 사용 가능
• 여러 그래픽 사전 설정 내장, 기본값은 "포커스" 효과
• 게임 UI 표시 이상을 방지하는 통합 사전 설정 UI 렌더링 필터 플러그인

사용 제안
• 보안 소프트웨어 오진이 발생하면 일시적으로 보호를 비활성화하거나 신뢰 목록에 추가

고급 설정
• "경량 셰이더"에서 나중에 전체 셰이더 목록을 얻으려면 "설치 디렉토리\ReShade\reshade-shaders\Full-Shaders.zip"을 압축 해제 ("현재 폴더에 압축 해제"하고 덮어쓰기)하면 모든 전체 셰이더를 얻을 수 있습니다

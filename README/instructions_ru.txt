ReShade & Mod Launcher - Введение в программное обеспечение

Важное заявление о безопасности
Это программное обеспечение использует технологию внедрения процессов для реализации функций улучшения графики ReShade и загрузки модов. Этот тип технического механизма может быть ошибочно оценен как потенциальный риск программным обеспечением безопасности, но на самом деле он используется только для оптимизации графики игры и управления модами и не содержит вредоносных действий. Если у вас есть опасения по поводу безопасности технологии внедрения, используйте с осторожностью.

Основное использование
• Установить
• При первом запуске программы следуйте инструкциям, чтобы выбрать основную программу игры или лаунчер XXMI
• При последующих запусках настройки повторять не нужно
• Запуск игры в один клик через ярлык на рабочем столе
• Нажмите клавишу Home в игре, чтобы переключить панель эффектов ReShade
• Путь хранения файлов модов: Каталог установки\Mods_Loader\mods

Основные функции
• Возможность выбора использования XXMI для запуска игры
• Внешняя загрузка ReShade для избежания конфликтов с родными файлами игры
• Автоматизированный процесс запуска, одновременно загружающий эффекты улучшения графики и моды игры
• Многоязычный интерфейс, адаптированный к языковой среде системы
• Механизм автоматического резервного копирования файлов конфигурации
• Интегрированный загрузчик модов (опциональная функция, используйте по необходимости)
• Предустановленные параметры оптимизации, готовы к использованию
• Встроенные несколько графических пресетов, по умолчанию используется эффект "Фокус"
• Интегрированный плагин фильтра рендеринга предустановленного UI для предотвращения аномального отображения интерфейса игры

Рекомендации по использованию
• При возникновении ложных срабатываний программного обеспечения безопасности временно отключите защиту или добавьте в список доверенных

Расширенные настройки
• Если вы хотите получить полный список шейдеров для "Облегченных шейдеров" позже, вы можете распаковать "Каталог установки\ReShade\reshade-shaders\Full-Shaders.zip" (непосредственно "Извлечь в текущую папку" с перезаписью), чтобы получить все полные шейдеры
